# FDE Screen

## Instructions

1) Ensure you have Python installed. Run 'python3 --version' in terminal to confirm.

2) Clone repo to desktop or desired folder.

3) Open fdescreen folder in IDE (VS Code reccommended).

4) Uncomment sort function (remove #) and fill params with desired values. The default is all 1s for width, height, length, and mass. 

5) Run 'python3 app.py' to get result.
